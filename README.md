# The Great Warrior

Playable prototypes, hosted on GitHub Pages.

- **Gig Run** (roguelike prototype): https://tshadey01.github.io/great-warrior/
- **Sound Lab** (music engine): https://tshadey01.github.io/great-warrior/sound-lab/

Sound on, please. Works on desktop (mouse + keyboard) and phones (touch).
Progress is saved in your own browser.

## Updating the build

    python3 scripts/build.py      # copies the latest HTML from the project folder
    git add -A && git commit -m "Update build" && git push

Pages redeploys automatically a minute or so after each push to `main`.
